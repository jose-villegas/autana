One oldest-first queue now feeds the night's board lanes instead of the lane/lanes modulo split: planned lanes, then joiners, take the next steps off its head, each after its own board's anchor, so no commit is dealt twice in a night and joiners stop repeating other boards' commits. The plan saves the queue in the data store, and the next night owes whatever no manifest since has attempted before any newer commit, so nothing is dropped across nights (a commit may be measured twice). Stacked on #1361.

| Piece | Before | After |
|---|---|---|
| Split | `position % lanes == lane` per board, joiners `0/1` | `night_queue` → `deal`: each lane takes the queue's next `min(capacity, --max-steps, share)` steps |
| Carry-over | each board after its own `last_attempted` | the last saved queue (`scoped/queue/<key>.json`) minus every commit attempted since, then every commit after its tip |
| Owed again | a failed capture behind a measured step, a commit no lane reached or had room for, a lane that wrote no manifest: lost | owed to the next night, first |
| First queued night | – | every commit after any board's `last_attempted` that no board's last manifest attempted, so an M1-capped modulo share loses nothing |
| First night ever | newest commit | the tip only |
| Unsized override | modulo split | each board takes an even run of the queue |
| `--from` | modulo share of that range | the queue is history from that commit; nothing is saved for the next night |
| `run --from/--max-steps` | replanned the lane's modulo share | reruns part of the lane's own dealt steps |
