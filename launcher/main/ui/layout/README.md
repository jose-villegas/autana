# ui/layout

Fixed-point placement. No drawing.

| File | Role |
|---|---|
| `ui_transform.h` | Affine transform of UI space to screen space, header-only |
| `ui_anchor.h` | Anchors and pivots for rectangle placement |
| `ui_layout.h` | `ui_layout_rect_t`, the rectangle the baked screen tables store; with conversion to `recti_t` |
