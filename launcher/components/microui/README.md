# microui

A tiny immediate-mode UI library: the controls, layout and input handling that
the shell's and apps' screens are built with. It is rxi's
[microui](https://github.com/rxi/microui) 2.02 (`MU_VERSION` in
`include/microui.h`), under the MIT license in `src/microui.c`, vendored here
with local changes. `git log -- launcher/components/microui` lists them.
