# Citations

The papers, books and specifications whose techniques this tree uses. A
document cites one by its number, as a superscript link to its row:
`<sup>[[3]](Citations.md#3)</sup>`, with the path relative to the citing file.
A number is permanent once given; a new source takes the next one. "Cited by"
lists every file that cites the row, and
[`check_doc_citations.py`](../scripts/gates/check_doc_citations.py) fails when
a cited number has no row, a row is cited nowhere, or the list differs from the
citing files.
